# Manual del Usuario — Introducción

## Bienvenido a la plataforma

Este manual te guiará por todas las funcionalidades disponibles como usuario de la plataforma web. Aquí encontrarás cómo navegar por el sitio, leer contenido, contactar con la empresa, cambiar el idioma y gestionar tu cuenta.

---

## ¿Qué puedo hacer como usuario?

Como usuario de la plataforma, puedes:

- **Navegar** por la página principal con sus secciones dinámicas y carrusel de imágenes.
- **Leer el blog** con artículos organizados por categorías.
- **Consultar páginas** de contenido (servicios, información, etc.).
- **Contactar** con la empresa a través del formulario de contacto.
- **Conocer** más sobre la empresa en la página «Sobre nosotros».
- **Cambiar el idioma** de la web entre español e inglés.
- **Registrarte** y crear una cuenta personal.
- **Iniciar sesión** y acceder a tu panel de usuario privado.
- **Consultar las páginas legales** (política de privacidad y cookies).
- **Usar la API REST** para integrar aplicaciones externas.

---

## Registro y cuenta de usuario

El registro en la plataforma es **gratuito**. Una vez registrado podrás:

- Acceder al **Panel de Usuario** (`/panel`) para gestionar tu perfil y tokens API.
- Obtener **tokens de acceso** para usar la API REST de la plataforma.

> **Nota:** No es necesario registrarse para navegar por el contenido público del sitio (blog, páginas, contacto, etc.).

---

## Idiomas disponibles

La plataforma está disponible en dos idiomas:

- 🇪🇸 **Español** (idioma por defecto)
- 🇬🇧 **Inglés**

Puedes cambiar el idioma en cualquier momento utilizando el selector de idioma disponible en la barra de navegación.
