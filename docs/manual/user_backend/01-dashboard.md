# Manual del Panel de Usuario — Dashboard

## Objetivo

El **Dashboard** es la primera pantalla que verás al acceder al Panel de Usuario. Te da la bienvenida y ofrece un resumen rápido de tu cuenta junto con accesos directos a las funcionalidades disponibles.

---

## Widget de bienvenida

Al entrar al Dashboard verás un **widget de bienvenida** que incluye:

| Información                 | Descripción                                                                |
|-----------------------------|----------------------------------------------------------------------------|
| **Mensaje de bienvenida**   | Un saludo personalizado con tu nombre: «Bienvenido, [Tu nombre]».          |
| **Tokens API activos**      | Número de tokens de acceso API que tienes actualmente activos.             |
| **Acceso rápido a Mi Perfil** | Enlace directo para ir a la página de edición de tu perfil.              |
| **Acceso rápido a Tokens API** | Enlace directo para ir a la página de gestión de tokens API.            |

---

## Navegación

Desde el Dashboard puedes acceder a las dos funcionalidades principales mediante:

1. **Los enlaces rápidos** del widget de bienvenida.
2. **El menú lateral izquierdo**, que contiene las entradas:
   - **Mi Perfil**: Para editar tus datos personales.
   - **Tokens API**: Para gestionar tus tokens de acceso a la API.

---

## Preguntas frecuentes

**¿El Dashboard se actualiza en tiempo real?**
El número de tokens activos y el mensaje de bienvenida se actualizan cada vez que cargas la página.

**¿Puedo personalizar el Dashboard?**
No, el Dashboard tiene un diseño fijo. Si necesitas funcionalidades adicionales, contacta al administrador del sistema.
